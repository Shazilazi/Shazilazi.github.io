{% comment %} Renders a small status-dot badge for a project: New, In Progress, or Complete. Silently renders nothing if no status is set, so it's safe to include on every project without requiring the front matter field. Usage: {% include status-badge.html status=project.status %} {% endcomment %} {% if include.status == "new" %} New {% elsif include.status == "in-progress" %} In Progress {% elsif include.status == "complete" %} Complete {% endif %}
